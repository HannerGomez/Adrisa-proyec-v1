# Requerimientos - Camisetas Expo Dic 2026

## Objetivo
Web vitrina para exhibir y vender camisetas con diseño especial, con exposición presencial en diciembre 2026.

## Público
Visitantes de la expo, seguidores de Instagram/TikTok, contactos por catálogo.

## Canales de venta
1. Instagram (@usuario)
2. TikTok (@usuario)
3. Web vitrina (este proyecto)
4. WhatsApp Business (número de contacto)

## Flujo de venta esperado
1. Usuario descubre por red social o link en bio.
2. Llega a la web vitrina → ve catálogo por diseño, talle, precio.
3. Acciona botón de compra/consulta → se abre chat de WhatsApp con mensaje prellenado (producto, talle, cantidad).
4. Se cierra la venta por WhatsApp (pago contraentrega/transferencia según definan).

## Entregables web
- Landing page / vitrina responsive (mobile first, ideal para redes).
- Catálogo con galería de diseños y fotos de modelos.
- Ficha por diseño: imagen, nombre, precio, talles disponibles, breve descripción.
- Botón flotante oCTA a WhatsApp.
- Página de contacto/información de envío.

## Entregables documentales
- Documento de requerimientos (este archivo).
- Catálogo de productos (CSV o JSON con datos).
- Guía de estilos: tipografías, paleta de colores, logo.
- Checklist pre-expo.

## Roadmap
- Semana 1: Definir identidad visual + subir material gráfico.
- Semana 2: Maquetado web + flujo WhatsApp.
- Semana 3: Contenido, textos, publicación.
- Semana 4: Pruebas, ajustes, deploy.
